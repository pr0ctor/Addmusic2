# Lower Octave (`<`)

## Overview

The Lower Octave command reduces the current octave by one.  

## Syntax

`<`

Examples:
- `<`

## Description

The Lower Octave command increases the current octave in the current channel or loop by one. If the current octave is `6`, the octave will not be raised any higher and will be kept at the maximum of `6`.
